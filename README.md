# AipFLkeysPopGen

This repository includes data and scripts to recreate analyses for the manuscript entitled "Environmentally-determined symbiont communities highlight flexibility of Aiptasia-algal symbiosis" currently available on bioRxiv (https://doi.org/10.64898/2026.05.11.724104).

The "host" directory contains scripts for 2bRAD bioinformatic analyses, clonal identification, and population genetics. The "symbiont" directory contains scripts for symbiont community and codivergence analyses using the output from SymPortal.
